# Cahier des charges (entrée brute)

Dépose ici le **cahier des charges détaillé** du projet (Markdown, PDF, etc.).

C'est l'**entrée humaine figée**. Le rôle **Product Owner** la transforme en découpage
structuré et traçable sous [`../../backlog/`](../../backlog/) :

- [`../../backlog/user_stories/`](../../backlog/user_stories/) — User Stories (`US-XXX`)
- [`../../backlog/features/`](../../backlog/features/) — Features (`FEAT-XXX.Y`)
- [`../../backlog/backlogs/`](../../backlog/backlogs/) — Backlogs (`BL-XXX`)

Fichier actuel : [`000_specifications.md`](000_specifications.md)
(cahier des charges AT Pro Pilotage).

- **Ici** : la source (le « d'où ça vient »).
- **Dans `docs/backlog/`** : la spec dérivée (le « ce qu'on en a fait »).

> Ne modifie pas le contenu déposé ici pour « corriger » la spec : si une clarification
> est nécessaire, elle se note dans les US / FEAT / BL dérivés, pas dans la source.
