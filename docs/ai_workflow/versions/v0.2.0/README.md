# Version v0.2.0 - Persistance PostgreSQL et imports idempotents

Ce dossier suit l'etat du lot `v0.2.0`.

La version a pour objectif de rendre persistables les modeles canoniques produits par `v0.1.0` dans PostgreSQL, avec idempotence, provenance, rollback controle et premieres commandes CLI d'exploitation.

Fichiers obligatoires :

- `version.yaml` ;
- `scope.md` ;
- `validation.md` ;
- `integration_matrix.yaml` ;
- `release_report.md`.
