# US-020 - Persister les appels et segments d'appels

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux enregistrer les `Call` et `CallSegment` issus du parseur sans dedoublonner incorrectement les mesures multi-lignes.

### Scenario nominal

1. Creer les tables appels.
2. Ajouter la cle unique `source_system`, `external_call_id`.
3. Ajouter une cle unique de segment.
4. Persister les durees consolidees.
5. Conserver les lignes sources.
6. Tester reimport identique et multi-segments.

### Criteres d'acceptation

- Un appel multi-lignes produit un seul appel global et les segments attendus.
- Reimporter le meme fichier ne double pas les appels.
- Les segments ne sont pas perdus.
- Les numeros sensibles ne sont pas stockes en clair si le modele les masque ou hashe.
