# US-006 - Parser un fichier d'appels sortants

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Transformer un CSV d'appels sortants ou contre-appels en `Call` et `CallSegment`.

### Donnees attendues

Colonnes typiques :

- `ID de l'appel` ;
- `Numero appelant` parfois vide ;
- `Numero appele` ;
- `Nom de l'agent` ;
- `Debut d'appel` ;
- `Fin d'appel` ;
- `Categorie de qualification` ;
- `Motif de qualification` ;
- `Noms de mesures` ;
- `Valeurs de mesures`.

### Scenario nominal

1. Detecter le type `outgoing_calls`.
2. Lire les lignes.
3. Normaliser les dates et durees.
4. Regrouper les mesures.
5. Creer des appels de direction `outgoing`.
6. Produire les segments agents.
7. Signaler les anomalies.

### Scenarios alternatifs

- Nom de fichier mal orthographie.
- Numero appelant vide.
- Absence de flux/service.
- Plusieurs mesures pour un meme segment.

### Criteres d'acceptation

- La detection fonctionne meme si le fichier s'appelle `appels sotants.csv`.
- Les champs absents dans les appels sortants sont optionnels.
- Les contre-appels sont representes comme appels sortants, sans rapprochement ticket.
