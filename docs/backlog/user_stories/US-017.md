# US-017 - Creer le schema PostgreSQL avec Alembic

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux des migrations Alembic reproductibles afin de creer les tables de reference, d'import et de donnees metier.

### Scenario nominal

1. Initialiser Alembic.
2. Declarer les metadonnees SQLAlchemy.
3. Creer la migration initiale.
4. Ajouter contraintes uniques et index.
5. Tester upgrade puis downgrade si la politique du depot l'exige.
6. Documenter les commandes de migration.

### Criteres d'acceptation

- Les migrations creent toutes les tables `v0.2.0`.
- Les contraintes d'unicite critiques existent en base.
- Les index utiles aux imports existent.
- La migration est rejouable sur base vide.
- La commande de statut base est documentee.
