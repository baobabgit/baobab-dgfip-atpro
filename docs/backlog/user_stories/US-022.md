# US-022 - Persister les activites journalieres agents

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux enregistrer les activites agents normalisees afin que les statistiques futures puissent lire une table canonique commune aux formats large et long.

### Scenario nominal

1. Creer la table `agent_daily_activity`.
2. Ajouter les colonnes de compteurs, durees, taux et raw metrics.
3. Ajouter une contrainte d'unicite adaptee.
4. Persister les activites issues des deux formats.
5. Gerer les conflits meme agent/meme date.
6. Tester idempotence et conflit.

### Criteres d'acceptation

- Les formats large et long alimentent la meme table.
- Reimporter la meme activite ne cree pas de doublon.
- Une activite contradictoire genere une alerte de conflit.
- Les totaux journaliers ne sont pas transformes en donnees horaires.
