# US-028 - Tester l'integration PostgreSQL et documenter v0.2.0

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de revue, je veux des tests d'integration PostgreSQL et une documentation de persistance afin de verifier que `v0.2.0` est exploitable et idempotente.

### Scenario nominal

1. Mettre en place l'infrastructure de tests PostgreSQL.
2. Tester migrations.
3. Tester repositories.
4. Tester import initial, reimport identique, conflit et rollback.
5. Mettre a jour contrats et documentation.
6. Mettre a jour le dossier de version `v0.2.0`.

### Criteres d'acceptation

- Les tests d'integration passent sur PostgreSQL reel ou conteneur de test.
- Le reimport identique ne cree aucun doublon.
- Le rollback est verifie.
- Les contrats et matrices ne referencent pas le template.
- Le rapport de release `v0.2.0` est present.
