# US-015 - Lancer PostgreSQL en environnement de developpement

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux disposer d'un PostgreSQL local reproductible afin de tester les migrations, les repositories et les imports idempotents.

### Scenario nominal

1. Ajouter la configuration Docker Compose minimale pour PostgreSQL.
2. Declarer les variables d'environnement necessaires.
3. Configurer un volume persistant.
4. Ajouter un healthcheck.
5. Documenter le demarrage et l'arret.
6. Verifier que l'application peut construire une URL de connexion.

### Criteres d'acceptation

- Un service PostgreSQL 17+ est decrit.
- La configuration ne stocke pas de secret reel.
- `.env.example` ou equivalent documente les variables.
- Le healthcheck permet d'attendre la disponibilite.
- Les tests d'integration peuvent utiliser cette base ou une base temporaire equivalente.
