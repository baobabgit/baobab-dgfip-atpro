# US-026 - Annuler un lot d'import

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant que pilote, je veux pouvoir annuler un import afin de retirer les donnees ajoutees par erreur sans supprimer les donnees apportees par d'autres lots.

### Scenario nominal

1. Selectionner un `import_batch`.
2. Verifier qu'il est annulable.
3. Identifier les donnees liees exclusivement a ce lot.
4. Marquer le lot comme `rolled_back`.
5. Supprimer ou desactiver les donnees selon la politique retenue.
6. Journaliser l'operation.

### Criteres d'acceptation

- Un lot deja annule ne peut pas etre annule deux fois sans message clair.
- Les donnees partagees avec d'autres lots ne sont pas supprimees.
- Les statistiques futures sont marquees invalidables si necessaire.
- Le rollback est teste sur appels, tickets et activites.
