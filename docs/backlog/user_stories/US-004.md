# US-004 - Previsualiser un fichier CSV parse

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Afficher un apercu des modeles metier generes sans persistance.

### Acteur principal

Pilote fonctionnel ou IA de developpement via CLI.

### Declencheur

Commande :

```bash
atpro file preview <path>
```

### Scenario nominal

1. Valider le fichier.
2. Construire les modeles metier.
3. Selectionner un nombre limite d'exemples.
4. Afficher un resume par type de modele.
5. Afficher les premieres erreurs et avertissements.

### Resultats attendus

Pour un fichier d'appels :

- nombre d'appels globaux ;
- nombre de segments ;
- nombre de mesures consolidees ;
- periode ;
- agents bruts detectes ;
- flux et services detectes ;
- exemples anonymises.

Pour un fichier tickets :

- nombre de tickets ;
- periode ;
- canaux ;
- statuts ;
- sites de repartition ;
- agents de qualification/resolution detectes.

Pour un fichier activites :

- nombre de jours ;
- nombre d'agents ;
- format large ou long ;
- mesures detectees ;
- activites reconstruites.

### Criteres d'acceptation

- La previsualisation ne doit pas afficher de numeros de telephone en clair.
- La previsualisation doit rester courte par defaut.
- Un mode JSON doit permettre une verification automatique.
