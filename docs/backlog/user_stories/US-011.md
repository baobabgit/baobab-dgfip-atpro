# US-011 - Produire un resultat de parsing standardise

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Fournir un contrat unique pour tous les parseurs.

### Scenario nominal

1. Recevoir les metadonnees fichier.
2. Recevoir les records produits.
3. Recevoir les erreurs et avertissements.
4. Calculer le statut global.
5. Retourner un `ParseResult`.

### Champs minimaux

- `file_metadata` ;
- `detected_type` ;
- `schema_version` ;
- `records` ;
- `warnings` ;
- `errors` ;
- `summary`.

### Criteres d'acceptation

- Tous les readers retournent le meme type de resultat.
- Le resultat est serialisable en JSON.
- Le resultat permet une sortie CLI lisible.
