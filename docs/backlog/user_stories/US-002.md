# US-002 - Inspecter un fichier CSV

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Permettre a l'utilisateur ou a une IA d'obtenir les metadonnees d'un fichier avant parsing complet.

### Acteur principal

Pilote fonctionnel ou IA de developpement via CLI.

### Pre-conditions

- Le fichier existe.
- Le fichier est lisible.
- Le fichier n'est pas modifie pendant l'inspection.

### Declencheur

Commande :

```bash
atpro file inspect <path>
```

### Scenario nominal

1. Recevoir un chemin de fichier.
2. Verifier l'existence et l'acces en lecture.
3. Calculer le SHA-256.
4. Detecter l'encodage probable.
5. Detecter le separateur.
6. Lire les en-tetes.
7. Detecter le type de fichier probable.
8. Detecter la version de schema probable.
9. Detecter la periode minimale et maximale si possible.
10. Retourner un rapport d'inspection.

### Scenarios d'erreur

- Fichier introuvable.
- Chemin vers un repertoire au lieu d'un fichier.
- Fichier vide.
- Encodage non detecte.
- Separateur non detecte.
- En-tetes absents.
- Type inconnu.

### Resultats attendus

Le resultat doit contenir :

- chemin original ;
- nom du fichier ;
- taille ;
- SHA-256 ;
- encodage ;
- separateur ;
- colonnes detectees ;
- type detecte ;
- version de schema ;
- periode detectee ;
- avertissements ;
- erreurs non bloquantes.

### Criteres d'acceptation

- L'inspection ne parse pas obligatoirement toutes les lignes.
- L'inspection ne cree aucune donnee persistante.
- Une faute dans le nom du fichier, par exemple `appels sotants.csv`, n'empeche pas la detection par colonnes.
- La sortie est disponible en mode lisible et en JSON si le CLI le supporte.
