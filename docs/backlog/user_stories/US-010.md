# US-010 - Normaliser les identites agents et sites

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Produire des valeurs normalisees permettant le rapprochement ulterieur, sans imposer de persistence en base.

### Scenario nominal

1. Recevoir une valeur brute.
2. Supprimer les espaces multiples.
3. Harmoniser la casse.
4. Comparer sans accents.
5. Gerer les tirets.
6. Identifier les formes `NOM Prenom` et `Prenom NOM` lorsque possible.
7. Retourner valeur brute, valeur normalisee et indices de confiance.

### Scenarios alternatifs

- Valeur vide.
- Encodage degrade.
- Nom compose.
- Prenom compose.
- Initiales ou groupe agent.

### Criteres d'acceptation

- La valeur brute est toujours conservee.
- La normalisation est deterministic.
- Les ambiguities ne sont pas tranchees silencieusement.
