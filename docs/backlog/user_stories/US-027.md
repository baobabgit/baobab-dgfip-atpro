# US-027 - Exploiter imports et referentiels via CLI

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'utilisateur technique, je veux importer des fichiers et gerer les referentiels via CLI afin d'exploiter le systeme sans interface Web.

### Scenario nominal

1. Executer `atpro import run`.
2. Lister les imports.
3. Afficher le detail d'un import.
4. Afficher les erreurs d'un import.
5. Annuler un import.
6. Lister agents et sites.
7. Ajouter alias et affectations datees.

### Criteres d'acceptation

- Les commandes import utilisent les memes cas d'usage que les repositories.
- Les sorties humaines et JSON sont disponibles pour les commandes critiques.
- Les codes de sortie sont documentes.
- Le CLI ne contient pas de SQL direct.
