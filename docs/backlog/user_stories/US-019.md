# US-019 - Tracer les lots d'import et les lignes rejetees

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant que pilote, je veux connaitre l'historique des imports, les fichiers traites et les lignes rejetees afin de comprendre la qualite des donnees chargees.

### Scenario nominal

1. Creer `import_batch`.
2. Creer `import_rejected_row`.
3. Enregistrer le SHA-256 du fichier.
4. Enregistrer type, schema, periode, statut et compteurs.
5. Enregistrer les erreurs de lignes masquees.
6. Exposer ces informations aux cas d'usage et au CLI.

### Criteres d'acceptation

- Un fichier importe produit un `import_batch`.
- Un fichier identique est detecte par SHA-256.
- Les lignes rejetees contiennent un payload masque.
- Le statut d'import est explicite : running, completed, completed_with_warnings, failed, rolled_back.
