# US-013 - Definir et verifier la fourniture des CSV de reference reels

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux connaitre la modalite officielle de fourniture des fichiers CSV reels de reference afin de pouvoir executer les tests sur fichiers de reference sans supposer l'existence d'un dossier absent ou de donnees sensibles versionnees.

### Contexte

Le cahier des charges distingue deux besoins :

- disposer de fixtures anonymisees versionnables ;
- verifier les parseurs sur les fichiers CSV reels de reference lorsque ces fichiers sont disponibles.

Les fixtures anonymisees ne remplacent pas les fichiers reels : elles permettent la CI, tandis que les fichiers reels permettent la validation fonctionnelle sur les exports historiques.

### Scenario nominal

1. Lire les options autorisees par le cahier des charges pour les sources de reference.
2. Constater si les fichiers reels sont presents localement.
3. Choisir ou documenter la modalite retenue :
   - `samples/reference/` pour des echantillons anonymises versionnables ;
   - volume Docker externe ;
   - dossier local non versionne ;
   - stockage documentaire hors depot ;
   - fixtures synthetiques uniquement en CI.
4. Creer la documentation de fourniture des CSV reels.
5. Ajouter une detection explicite de l'absence des fichiers reels.
6. Prevoir des tests optionnels ou marques qui s'executent seulement lorsque les fichiers reels sont disponibles.

### Scenarios alternatifs

- Si les fichiers reels ne peuvent pas etre versionnes, fournir uniquement des fixtures anonymisees en CI et documenter la commande locale de validation.
- Si les fichiers reels sont fournis par volume externe, documenter le chemin attendu et la variable d'environnement.
- Si aucun fichier reel n'est disponible, marquer la validation de reference comme bloquee fonctionnellement mais ne pas bloquer les tests unitaires.

### Resultats attendus

- Le mode de fourniture des CSV reels est documente.
- Les tests automatiques ne dependent pas silencieusement d'un dossier absent.
- La validation sur fichiers reels est possible en local lorsque les sources sont disponibles.

### Criteres d'acceptation

- Un fichier de documentation indique ou placer les CSV reels.
- Une variable ou configuration explicite permet de pointer vers les CSV reels.
- L'absence des fichiers reels produit un message clair, pas un faux succes.
- Les fixtures anonymisees restent suffisantes pour la CI.
- Aucun fichier sensible reel n'est ajoute au depot par cette user story.
