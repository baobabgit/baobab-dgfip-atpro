# US-023 - Executer un import transactionnel depuis ParseResult

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant que pilote, je veux importer un fichier parse avec garantie transactionnelle afin qu'un echec n'enregistre pas un etat partiel incoherent.

### Scenario nominal

1. Recevoir un `ParseResult` valide.
2. Creer un `import_batch` en statut `running`.
3. Persister les donnees dans une transaction.
4. Enregistrer inserted, updated, skipped et rejected.
5. Commit en cas de succes.
6. Rollback en cas d'erreur bloquante.
7. Passer le lot au statut final.

### Criteres d'acceptation

- Aucune donnee metier partielle ne reste apres erreur fatale.
- Les compteurs d'import sont coherents.
- Le fichier identique est detecte avant duplication metier.
- Les warnings non bloquants n'annulent pas l'import.
