# US-025 - Mettre en quarantaine les lignes rejetees

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant que pilote, je veux retrouver les lignes rejetees et leurs motifs afin de corriger les sources ou enrichir les parseurs.

### Scenario nominal

1. Recevoir les erreurs du `ParseResult`.
2. Masquer les donnees sensibles.
3. Enregistrer numero de ligne, colonne, code, message et severite.
4. Associer chaque rejet a un `import_batch`.
5. Exposer les rejets via repository et CLI.

### Criteres d'acceptation

- Les lignes rejetees sont consultables par import.
- Les payloads sensibles sont masques.
- Les erreurs fatales sont distinguees des warnings.
- L'import peut etre `completed_with_warnings` si seules des lignes non bloquantes sont rejetees.
