# US-012 - Construire des fixtures de test anonymisees

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Permettre les tests automatises sans dependre de donnees sensibles ni de fichiers absents.

### Scenario nominal

1. Identifier les schemas de reference.
2. Creer de petits CSV anonymises par type.
3. Couvrir les variantes connues.
4. Conserver des cas invalides.
5. Documenter le lien entre fixture et scenario de test.

### Criteres d'acceptation

- Les fixtures ne contiennent aucun numero, email ou identifiant reel.
- Les fixtures couvrent appels entrants, appels sortants, tickets, activites large et activites long.
- Les fixtures peuvent etre versionnees.
- Les tests peuvent tourner sans fichiers reels.
