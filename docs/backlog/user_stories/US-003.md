# US-003 - Valider un fichier CSV

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Verifier qu'un fichier peut etre transforme en modeles metier sans erreur bloquante.

### Acteur principal

Pilote fonctionnel ou IA de developpement via CLI.

### Declencheur

Commande :

```bash
atpro file validate <path>
```

### Scenario nominal

1. Inspecter le fichier.
2. Selectionner le reader adapte.
3. Lire toutes les lignes.
4. Normaliser les valeurs.
5. Construire les modeles metier.
6. Collecter les erreurs et avertissements.
7. Produire un `ParseResult`.
8. Retourner un statut global.

### Statuts possibles

| Statut | Signification |
|---|---|
| `valid` | Toutes les donnees utiles sont exploitables |
| `valid_with_warnings` | Parsing possible mais anomalies non bloquantes |
| `invalid` | Erreurs bloquantes empechant l'exploitation |
| `unknown_format` | Type ou schema non reconnu |

### Scenarios d'erreur

- Type non reconnu.
- Schema connu mais colonnes obligatoires manquantes.
- Dates impossibles.
- Durees negatives.
- Appel sans identifiant.
- Ticket sans numero.
- Activite sans periode.
- Mesures contradictoires.

### Criteres d'acceptation

- Les erreurs indiquent le numero de ligne lorsque possible.
- Les avertissements sont separes des erreurs bloquantes.
- Les donnees personnelles sensibles sont masquees dans les messages longs.
- Le CLI retourne un code de sortie non nul en cas de fichier invalide.
