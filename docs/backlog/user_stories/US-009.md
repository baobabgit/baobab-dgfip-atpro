# US-009 - Parser un fichier activites agents format long

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Reconstruire une activite journaliere a partir de lignes `mesure/valeur`.

### Donnees attendues

Colonnes typiques :

- `Periode` ;
- `Agent / Groupe Agent` ;
- `Noms de mesures` ;
- `Valeurs de mesures`.

### Scenario nominal

1. Detecter le format long.
2. Grouper par date et agent.
3. Mapper chaque nom de mesure vers un champ canonique.
4. Convertir chaque valeur selon son type attendu.
5. Produire un `AgentDailyActivity` par date et agent.
6. Conserver les mesures inconnues dans `raw_metrics`.

### Scenarios alternatifs

- Mesure inconnue.
- Mesure dupliquee avec meme valeur.
- Mesure dupliquee avec valeur differente.
- Agent non reconnu.
- Valeur non convertible.

### Criteres d'acceptation

- Le format long produit le meme modele canonique que le format large.
- Les mesures contradictoires sont signalees.
- Les mesures inconnues ne bloquent pas tout le fichier si elles ne sont pas obligatoires.
