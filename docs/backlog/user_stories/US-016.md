# US-016 - Configurer SQLAlchemy, sessions et Unit of Work

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : User story  
Statut : pret pour implementation

### Objectif

En tant qu'IA de developpement, je veux un acces base structure autour de SQLAlchemy et d'une Unit of Work afin que les imports soient transactionnels et testables.

### Scenario nominal

1. Ajouter la configuration de connexion.
2. Creer l'engine SQLAlchemy.
3. Creer la fabrique de sessions.
4. Creer une Unit of Work.
5. Gerer commit, rollback et fermeture.
6. Ajouter tests unitaires et integration.

### Criteres d'acceptation

- Les cas d'usage applicatifs ne manipulent pas directement l'engine.
- La Unit of Work garantit rollback en cas d'erreur.
- Les sessions ne fuient pas entre tests.
- Les erreurs base sont converties en erreurs applicatives explicites.
