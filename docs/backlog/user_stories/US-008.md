# US-008 - Parser un fichier activites agents format large

Projet : AT Pro Pilotage  
Version cible : `v0.1.0`  
Type : User story  
Statut : pret pour implementation


### Objectif

Transformer un CSV d'activites agents format large en `AgentDailyActivity`.

### Donnees attendues

Colonnes typiques :

- `Periode` ;
- `Agent / Groupe Agent` ;
- `Appels decroches` ;
- `Appels recus` ;
- `Duree de mise en garde` ;
- `Nombre d'appels sortants` ;
- `Taux de decroches` ;
- `Temps login` ;
- `Temps non pret` ;
- `Temps pret` ;
- `Temps total dans l'etat rona` ;
- `Temps telephone` ;
- `Temps total de communication des appels entrants` ;
- `Temps total de communication des appels sortants` ;
- `Temps total de post appel sur agent`.

### Scenario nominal

1. Detecter le format large.
2. Lire une ligne par agent et jour.
3. Normaliser la date.
4. Normaliser le nom agent.
5. Convertir les compteurs.
6. Convertir les durees `HH:MM:SS`.
7. Convertir les pourcentages.
8. Produire un `AgentDailyActivity`.

### Scenarios alternatifs

- Date en francais, par exemple `15 juin 2026`.
- Pourcentage avec virgule.
- Duree vide.
- Valeur numerique vide.
- Agent mal encode.

### Criteres d'acceptation

- Une ligne valide produit une activite journaliere.
- Les champs inconnus sont conserves dans `raw_metrics` si utile.
- Les totaux journaliers ne sont jamais convertis en occupation horaire.
