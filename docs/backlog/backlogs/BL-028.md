# BL-028 - Migrer les tables imports et referentiels

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Creer la premiere partie du schema PostgreSQL : imports, rejets, sites, agents, alias et affectations.

### Dependances

- BL-027

### Taches

1. Definir les modeles ORM `site`, `agent`, `agent_alias`, `agent_site_assignment`.
2. Definir les modeles ORM `import_batch` et `import_rejected_row`.
3. Ajouter timestamps techniques.
4. Ajouter contraintes uniques et index.
5. Ajouter foreign keys.
6. Generer ou ecrire la revision Alembic.
7. Verifier le schema sur base vide.

### Livrables

- Modeles ORM referentiels/imports.
- Revision Alembic.
- Tests d'inspection de schema.

### Tests

- Migration sur base vide.
- Contraintes uniques agents/sites/alias.
- Foreign keys imports/rejets.

### Acceptation

- Les lots d'import et referentiels peuvent etre persistés avant les donnees metier.
