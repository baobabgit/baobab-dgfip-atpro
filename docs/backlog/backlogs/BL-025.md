# BL-025 - Implementer engine et sessions SQLAlchemy

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Creer l'infrastructure SQLAlchemy de base pour les repositories.

### Dependances

- BL-023
- BL-024

### Taches

1. Creer la base declarative SQLAlchemy.
2. Definir les conventions de nommage des contraintes.
3. Implementer la creation d'engine depuis la configuration.
4. Implementer la fabrique de sessions.
5. Eviter toute connexion lors de l'import des modules.
6. Ajouter des helpers de test si necessaire.

### Livrables

- `src/atpro/infrastructure/database/base.py`.
- `src/atpro/infrastructure/database/session.py`.
- Tests associes.

### Tests

- Creation d'engine avec URL valide.
- Creation et fermeture de session.
- Import des modules sans effet reseau.

### Acceptation

- Les repositories peuvent recevoir une session injectee.
- Le code respecte SQLAlchemy 2.x et le typage strict.
