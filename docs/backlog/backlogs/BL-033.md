# BL-033 - Implementer repositories Call et CallSegment

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Persister les appels globaux et leurs segments sans doublon.

### Dependances

- BL-029
- BL-032

### Taches

1. Implementer `CallRepository`.
2. Implementer `CallSegmentRepository` ou une methode dediee dans `CallRepository`.
3. Preserver l'ordre des segments.
4. Lier chaque ligne au lot d'import.
5. Utiliser les empreintes de segment.
6. Detecter les contenus differents a cle metier identique.

### Livrables

- Repository appels.
- Tests repositories.

### Tests

- Insertion appel simple.
- Insertion appel multi-segments.
- Reimport identique.
- Conflit appel.
- Conflit segment.

### Acceptation

- Aucun segment legitime n'est perdu par deduplication trop large.
