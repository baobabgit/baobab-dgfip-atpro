# BL-023 - Ajouter dependances et configuration PostgreSQL

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Preparer le package Python pour se connecter a PostgreSQL et executer les migrations.

### Dependances

- BL-022

### Taches

1. Ajouter les dependances SQLAlchemy, Alembic et driver PostgreSQL.
2. Ajouter les dependances de test necessaires aux tests PostgreSQL.
3. Creer le module de configuration base de donnees.
4. Lire les variables `ATPRO_DATABASE_URL` ou composants separes.
5. Fournir `.env.example` sans secret reel.
6. Masquer les mots de passe dans les messages et representations.
7. Declarer les marqueurs pytest utiles si necessaire.

### Livrables

- Configuration base de donnees.
- `.env.example`.
- Mise a jour des dependances projet.

### Tests

- Tests unitaires de construction d'URL.
- Tests de masquage.
- Validation de configuration absente ou incomplete.

### Acceptation

- La configuration est importable sans connexion reseau.
- Le mot de passe n'apparait pas en clair dans les sorties de test.
