# BL-040 - Implementer l'annulation d'un lot d'import

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Permettre le rollback controle d'un import deja realise.

### Dependances

- BL-037

### Taches

1. Definir la strategie d'annulation selon ADR : suppression physique ou marquage.
2. Implementer le cas d'usage `RollbackImport`.
3. Verifier que le lot existe et est annulable.
4. Annuler les donnees liees au lot dans l'ordre correct.
5. Conserver l'historique du lot et des rejets.
6. Refuser une annulation double.
7. Retourner un resultat detaille.

### Livrables

- Cas d'usage de rollback.
- Tests applicatifs.

### Tests

- Rollback import complet.
- Rollback import partiel.
- Lot inexistant.
- Lot deja annule.

### Acceptation

- Apres rollback, une consultation metier ne voit plus les donnees du lot annule.
