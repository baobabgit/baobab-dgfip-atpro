# BL-024 - Fournir PostgreSQL via Docker Compose

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : done


### Objectif

Permettre a un developpeur de lancer une base PostgreSQL locale reproductible.

### Dependances

- BL-023

### Taches

1. Ajouter ou completer le fichier Compose de developpement.
2. Declarer le service PostgreSQL 17.
3. Ajouter volume persistant, healthcheck et variables documentees.
4. Configurer un port local modifiable.
5. Documenter demarrage, arret, nettoyage et diagnostic.
6. Verifier que le compose ne contient pas de secret production.

### Livrables

- Fichier Compose de developpement.
- Documentation `docs/operations/database.md`.

### Tests

- Demarrage du service.
- Verification du healthcheck.
- Connexion avec la configuration documentee.

### Acceptation

- PostgreSQL peut etre lance sans installation locale.
- La documentation indique clairement comment nettoyer le volume.
