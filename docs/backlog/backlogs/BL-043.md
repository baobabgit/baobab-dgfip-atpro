# BL-043 - Mettre en place les tests d'integration PostgreSQL

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Fournir l'infrastructure de test qui execute migrations et repositories contre PostgreSQL.

### Dependances

- BL-024
- BL-027

### Taches

1. Creer `tests/integration/`.
2. Declarer les marqueurs pytest necessaires.
3. Creer les fixtures de connexion PostgreSQL.
4. Appliquer les migrations avant les tests.
5. Nettoyer la base entre tests.
6. Documenter la commande d'execution.
7. Veiller a l'absence de warning pytest non declare.

### Livrables

- Fixtures integration PostgreSQL.
- Documentation tests.
- Mise a jour `pyproject.toml` si necessaire.

### Tests
