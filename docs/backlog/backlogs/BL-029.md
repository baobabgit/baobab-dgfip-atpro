# BL-029 - Migrer les tables metier importees

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Creer les tables PostgreSQL pour appels, segments, tickets et activites journalieres agents.

### Dependances

- BL-028

### Taches

1. Definir les modeles ORM `call` et `call_segment`.
2. Definir le modele ORM `ticket`.
3. Definir le modele ORM `agent_daily_activity`.
4. Ajouter les liens vers `import_batch`, `agent` et `site`.
5. Ajouter les contraintes d'unicite metier.
6. Ajouter les colonnes d'empreinte normalisee.
7. Completer la revision Alembic ou creer une revision dependante.

### Livrables

- Modeles ORM metier.
- Migration Alembic.
- Tests d'inspection de schema.

### Tests

- Migration sur base vide.
- Contraintes uniques appels, segments, tickets et activites.
- Verification des types date/heure et durees.

### Acceptation

- Toutes les sorties canoniques de v0.1.0 ont une cible relationnelle.
