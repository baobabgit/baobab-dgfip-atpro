Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Installer le mecanisme de migration officiel du projet.

### Dependances

### Taches

1. Creer `alembic.ini` et le dossier `migrations/`.
2. Connecter Alembic a la configuration base du projet.
3. Importer les metadonnees SQLAlchemy.
4. Documenter `upgrade head` et les preconditions.
5. Prevoir une commande ou une section Makefile si le depot l'utilise.

### Livrables

- Documentation de migration.

- `upgrade head` fonctionne apres creation de la migration initiale.
