# BL-026 - Implementer la Unit of Work SQLAlchemy

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Encapsuler les transactions PostgreSQL derriere une interface applicative.

### Dependances

- BL-025

### Taches

1. Creer le port applicatif de Unit of Work.
2. Creer l'implementation SQLAlchemy.
3. Definir le cycle de vie `enter`, `commit`, `rollback`, `close`.
4. Exposer les repositories lorsque ceux-ci seront disponibles.
5. Ajouter les erreurs techniques utiles.
6. Tester rollback automatique sur exception.

### Livrables

- Port applicatif Unit of Work.
- Implementation SQLAlchemy.
- Tests unitaires et integration minimale.

### Tests

- Commit explicite.
- Rollback automatique.
- Fermeture de session.
- Erreur de reutilisation si applicable.

### Acceptation

- Les cas d'usage applicatifs ne manipulent pas directement `Session`.
