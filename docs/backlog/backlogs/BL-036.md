# BL-036 - Implementer empreintes et detection de doublons

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Fournir les fonctions communes d'empreinte fichier et d'empreinte metier normalisee.

### Dependances

- BL-032
- BL-033
- BL-034
- BL-035

### Taches

1. Implementer le calcul SHA-256 fichier.
2. Implementer une serialisation canonique pour les empreintes metier.
3. Normaliser valeurs vides, dates et durees avant empreinte.
4. Ajouter tests de stabilite.
5. Exposer un resultat `inserted`, `ignored`, `updated`, `conflict`.
6. Documenter les champs inclus par type de donnee.

### Livrables

- Service d'empreintes.
- Tests unitaires.
- Documentation courte dans `docs/operations/imports.md`.

### Tests

- Meme contenu, meme empreinte.
- Ordre de colonnes different, meme empreinte si modele identique.
- Difference significative, empreinte differente.

### Acceptation

- Les repositories utilisent une definition commune de l'identite de contenu.
