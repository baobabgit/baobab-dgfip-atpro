# BL-038 - Implementer la politique de conflit

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Rendre explicite et testable le comportement face aux donnees deja connues mais modifiees.

### Dependances

- BL-036
- BL-037

### Taches

1. Definir les modes autorises pour v0.2.0.
2. Choisir le mode par defaut : `fail_on_change` sauf decision ADR contraire.
3. Implementer le service de comparaison.
4. Produire un diagnostic masque des differences.
5. Appliquer la politique dans les repositories ou le cas d'usage.
6. Documenter le niveau de configuration : global en v0.2.0.

### Livrables
