# BL-045 - Couvrir le rollback par tests d'integration

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Verifier sur PostgreSQL reel qu'un lot d'import peut etre annule proprement.

### Dependances

- BL-040
- BL-043

### Taches

1. Importer un lot contenant plusieurs familles de donnees.
2. Executer le rollback.
3. Verifier la disparition ou neutralisation des donnees metier.
4. Verifier la conservation du lot et des rejets.
5. Verifier l'impossibilite d'annuler deux fois.
6. Documenter les limites du rollback v0.2.0.

### Livrables

- Tests integration rollback.
- Documentation limite rollback.

### Tests

- Rollback complet.
- Rollback partiel.
- Double rollback refuse.

### Acceptation

- Le rollback est transactionnel et observable.
