# BL-037 - Implementer le cas d'usage ImportParsedFile

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Brancher les resultats du parseur v0.1.0 sur la persistance v0.2.0 dans une transaction unique.

### Dependances

- BL-026
- BL-032
- BL-036

### Taches

1. Definir la commande applicative d'import.
2. Definir le resultat applicatif d'import.
3. Creer le lot d'import.
4. Persister chaque modele metier supporte.
5. Persister warnings et erreurs rejetables.
6. Mettre a jour les compteurs.
7. Commit uniquement en fin de traitement.
8. Rollback sur erreur bloquante.

### Livrables

- Cas d'usage `ImportParsedFile`.
- Tests applicatifs.

### Tests

- Import complet.
- Import partiel avec rejets.
- Fichier deja importe.
- Erreur bloquante avec rollback.

### Acceptation

- Le parsing et la persistance sont raccordes sans SQL dans le parseur.
