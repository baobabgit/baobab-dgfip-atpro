# BL-034 - Implementer repository Ticket

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Persister les tickets issus des CSV normalises.

### Dependances

- BL-029
- BL-032

### Taches

1. Implementer `TicketRepository`.
2. Mapper les champs canoniques utiles aux statistiques futures.
3. Lier agents, sites et lot d'import lorsque disponibles.
4. Appliquer la contrainte `source_system + ticket_number`.
5. Detecter une modification de contenu.
6. Ne pas stocker les donnees personnelles exclues du modele.
