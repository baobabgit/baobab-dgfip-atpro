# BL-044 - Couvrir l'idempotence par tests d'integration

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Verifier sur PostgreSQL reel que les reimports ne creent pas de doublons.

### Dependances

- BL-037
- BL-043

### Taches

1. Creer un scenario d'import complet.
2. Rejouer le meme import.
3. Verifier les compteurs `inserted` et `ignored`.
4. Verifier les contraintes uniques en base.
5. Tester un chevauchement partiel.
6. Tester une cle metier identique avec contenu different.

### Livrables

- Tests integration idempotence.

### Tests

- Reimport meme fichier.
- Reimport donnees chevauchantes.
- Conflit contenu different.

### Acceptation

- Le second import identique ne cree aucune ligne metier supplementaire.
