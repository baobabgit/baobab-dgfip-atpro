# BL-042 - Ajouter les commandes CLI referentiels

Projet : AT Pro Pilotage  
Version cible : `v0.2.0`  
Type : Backlog de livraison  
Statut : pending


### Objectif

Permettre la preparation minimale des sites, agents, alias et affectations depuis le CLI.

### Dependances

- BL-030
- BL-031

### Taches

1. Ajouter `atpro agent list`.
2. Ajouter `atpro agent show`.
3. Ajouter `atpro agent add-alias`.
4. Ajouter `atpro site list`.
5. Ajouter `atpro site show`.
6. Ajouter `atpro assignment add`.
7. Valider les dates et identifiants.
8. Tester les messages d'erreur.
